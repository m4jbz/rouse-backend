# Carpeta api

Aquí se encuentra toda la información sobre las rutas de la API también llamados
endpoints.

El archivo endpoints.py es solo un agrupador de todos los endpoints, nada más.

Dentro de la carpeta routes/ se encuentran los archivos con nombres de las tablas
de la DB, cada uno cuenta con código parecido ya que cumplen la misma función.
Recibir peticiones del frontend, manejarlas de manera correcta con formateo,
verificación de errores, y logica necesaria, y devolver una respuesta con su respectivo
código de error.
